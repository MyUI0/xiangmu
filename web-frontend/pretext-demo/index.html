简介

Pretext 是一个现代化的文档展示系统，专注于提供优雅的阅读体验和强大的内容管理功能。无论您是在编写技术文档、API 说明还是产品手册，Pretext 都能帮助您创建专业美观的文档网站。

系统采用模块化设计，支持丰富的内容展示格式，包括代码块、表格、图片等元素，同时保持了极致的性能和可访问性。

核心功能

响应式设计

完美适配各种设备屏幕尺寸，从手机到大屏显示器都能提供最佳阅读体验。

代码高亮

内置多种编程语言高亮支持，让代码示例更加清晰易读。

主题切换

支持亮色/暗色主题切换，保护眼睛，提升阅读舒适度。

使用示例

JavaScript 
// 创建一个简单的示例
class Document {
    constructor(title, content) {
        this.title = title;
        this.content = content;
    }
    
    render() {
        return `
            <article>
                <h1>${this.title}</h1>
                <div>${this.content}</div>
            </article>
        `;
    }
}

// 使用示例
const doc = new Document('Hello Pretext', '这是一个简单的文档示例');
console.log(doc.render());
提示： 点击右上角的复制按钮可以快速复制代码。
